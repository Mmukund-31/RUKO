### Unit and API tests
`uv run python -m pytest -q` → **106 passed**. The 90 tests from before V2 are unchanged and still pass.

The new `tests/test_v2_live.py` covers:
- the signalling relay, rejecting unknown rooms, ICE/TURN config and the QR code;

### Bugs found by these tests and fixed
- The caller saying "we have **sent** an OTP" was counted as the user reporting a loss.
- In "never ask for your OTP **or PIN**", the negation didn't reach PIN.
- "Blocked **today**" wasn't treated as urgency.
- The first alert was throttled because the cooldown clock started at 0.
- A critical alert held back by the cooldown waited for the caller to say something else.
- The caller page's "ended" state was overwritten.
